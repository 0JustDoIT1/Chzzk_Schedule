# 스트리머 후보 대조 · 2026-11-17

로컬 위키 문서 제목 후보 1,659개를 검증된 채널 328개와 대조했다. 이 수치는 채널 링크 연결 상태이며 현재 파트너 자격이나 다음 방송 예정 여부를 뜻하지 않는다. 11월 16일 추가 검토에서 잘못 수집된 문서 제목 `분룬:카린(인터넷 방송인)`을 [카린 문서](https://d.namu.moe/w/카린(인터넷%20방송인))와 [소속사 채널 안내](https://charonuniverse.com/notice/?bmode=view&idx=166543713)를 대조해 기존 카린 채널에 연결했다.

| 구분 | 건수 |
| --- | ---: |
| 문서 제목과 채널명 일치 | 229 |
| `(인터넷 방송인)` 등 문서 구분자를 제거하면 일치 | 44 |
| 본명·활동명 및 잘못 수집된 제목 연결을 개별 검토 | 53 |
| 채널 ID 연결 완료 | 326 |
| 검증 대기 | 1,333 |

파트너 분류 189개 중 181개를 채널 ID와 연결했다. 남은 8개 중 `치지직/소속 파트너 스트리머 목록`은 인물 문서가 아니다. 나머지 7개는 채널 ID 또는 문서 제목의 정확성을 충분히 확인하지 못한 항목이다. 후보라는 이유만으로 공개 스트리머로 등록하지 않는다.

| 미연결 파트너 후보 | 미연결 파트너 후보 |
| --- | --- |
| 박박준석 | 뽀힐러 |
| 손민우(프로게이머) | 이늦잠(인터넷 방송인) |
| 이혁규 | 이훈민 |
| 조성빈(프로게이머) | 치지직/소속 파트너 스트리머 목록 |


검증된 본명·활동명과 잘못 수집된 제목의 연결은 `apps/back-end/data/verified-namu-title-aliases.json`에 명시했다. `apps/back-end/scripts/audit-namu-streamer-candidates.js`를 실행하면 최신 채널 시드에 대해 분류별 건수와 미연결 파트너 제목을 다시 계산한다. 로컬 DB에는 `audit-namu-streamer-candidates.js --apply`로 연결 상태를 반영한다.

남은 전체 후보 1,333개에는 위키의 과거 활동명, 현재 비활동 채널, 같은 이름의 다른 인물, 채널 링크를 확인할 수 없는 문서가 섞일 수 있다. 향후 채널을 추가할 때에는 채널 ID와 인물 연결 출처를 함께 기록하고 이 감사를 재실행한다.
