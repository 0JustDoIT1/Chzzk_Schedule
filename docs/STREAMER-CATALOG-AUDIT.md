# 스트리머 후보 대조 · 2026-11-17

## 현재 상태 · 2026-11-19

사용자 결정에 따라 아래 조사 기록의 미연결 인물 후보 6명은 비공개 후보 컬렉션에서도 제거했다. 원본 위키 수집 JSON은 과거 자료로 보존하고, 가져오기에서는 `excluded-namu-streamer-candidates.json`의 제목을 제외한다. 현재 포함 후보는 1,653건이며 채널 연결 327건, 미연결 1,326건이다. 파트너 분류의 유일한 미연결 항목은 인물 문서가 아닌 `치지직/소속 파트너 스트리머 목록`이다. 아래의 과거 건수와 조사 내역은 당시 기록이다.

로컬 위키 문서 제목 후보 1,659개를 검증된 채널 328개와 대조했다. 이 수치는 채널 링크 연결 상태이며 현재 파트너 자격이나 다음 방송 예정 여부를 뜻하지 않는다. 11월 16일 추가 검토에서 잘못 수집된 문서 제목 `분룬:카린(인터넷 방송인)`을 [카린 문서](https://d.namu.moe/w/카린(인터넷%20방송인))와 [소속사 채널 안내](https://charonuniverse.com/notice/?bmode=view&idx=166543713)를 대조해 기존 카린 채널에 연결했다.

검증된 본명·활동명과 잘못 수집된 제목의 연결은 `apps/back-end/data/verified-namu-title-aliases.json`에 명시했다. `apps/back-end/scripts/audit-namu-streamer-candidates.js`를 실행하면 최신 채널 시드에 대해 분류별 건수와 미연결 파트너 제목을 다시 계산한다. 로컬 DB에는 `audit-namu-streamer-candidates.js --apply`로 연결 상태를 반영한다.

남은 전체 후보 1,333개에는 위키의 과거 활동명, 현재 비활동 채널, 같은 이름의 다른 인물, 채널 링크를 확인할 수 없는 문서가 섞일 수 있다. 향후 채널을 추가할 때에는 채널 ID와 인물 연결 출처를 함께 기록하고 이 감사를 재실행한다.

## 2026-11-18 로컬 후보 감사 재확인

`node apps/back-end/scripts/audit-namu-streamer-candidates.js`를 변경 적용 없이 실행했다. 후보 1,659개, 채널 연결 326개(제목 일치 229개, 문서 구분자 제거 44개, 검토한 별칭 53개), 미연결 1,333개로 위 표와 일치했다. 파트너 분류 미연결 8개 중 1개는 인물 문서가 아니며, 나머지 7명의 채널 ID는 여전히 확정되지 않았다. 이번 재확인에서는 공개 시드와 DB를 변경하지 않았다.
## 2026-11-18 이혁규 후보 연결

이혁규의 선수 활동명 `Dambi`는 [선수 프로필](https://www.vlr.gg/player/31827/dambi)에서 확인했다. [위플뷰의 NS Dambi 채널 기록](https://weflview.com/channel/chzzk/3fab37f4883eee95423be3546af001c8)은 32자리 채널 ID `3fab37f4883eee95423be3546af001c8`과 [치지직 채널](https://chzzk.naver.com/3fab37f4883eee95423be3546af001c8)을 연결한다. 두 자료의 `Dambi` 명칭과 NS 소속 기록을 대조해 같은 인물의 채널로 판단했다. 이 판단은 채널 식별에만 사용하며 현재 소속팀, 치지직 파트너 자격 또는 미래 방송 일정을 확정하지 않는다.

`verified-chzzk-channels.json`에 `NS Dambi` 1건과 `verified-namu-title-aliases.json`에 `이혁규 → NS Dambi` 연결을 추가했다. 변경 전 읽기 전용 감사 결과는 연결 327건, 미연결 1,332건(파트너 분류 7건 중 인물 후보 6건, 목록 문서 1건)이었다. 로컬 `Chzzk` 개발 DB에서 시드 미리보기 `missing: 1`을 확인한 뒤 `--apply`로 스트리머 1건과 후보의 채널 연결을 기록했다. 재실행 미리보기는 `missing: 0`, 공개 스트리머 총 334건이다. 운영 DB는 변경하지 않았다.

남은 인물 후보 6명(박박준석, 뽀힐러, 손민우, 이늦잠, 이훈민, 조성빈)은 이름 또는 선수 활동명만으로 특정 치지직 채널 ID를 확정하지 않았다. 이늦잠 문서와 이미 등록된 늦잠 채널의 동일인 여부도 보류한다. 되돌릴 때는 로컬 DB의 `NS Dambi` 스트리머와 `이혁규` 후보 연결만 개별 확인 후 제거하고, 이번 JSON 항목을 되돌린다. 기존 일정·다른 스트리머 문서는 건드리지 않는다.

## 2026-11-19 미연결 인물 6명 재검색

읽기 전용 후보 감사 결과는 연결 327건, 미연결 1,332건이며 파트너 미연결 항목은 인물 6명과 목록 문서 1건이다. 공개 검색에서 [박박준석 문서](https://www.namu.moe/w/박박준석)의 `iamjunsuk`, [손민우 선수 기록](https://liquipedia.net/leagueoflegends/Pleata)의 `Pleata`, [농심 선수단](https://www.ns-esports.com/page/27)의 이훈민 `SIRI`·조성빈 `illusion` 활동명은 다시 확인했지만 각 인물의 직접 치지직 채널 URL은 찾지 못했다. 뽀힐러는 동명 계정과 본인의 연결 근거가 부족하다.

`이늦잠`은 [늦잠 본인 유튜브 영상 제목](https://www.youtube.com/watch?v=aok94Psvw6I)에 쓰이는 호칭이고, [늦잠 문서](https://d.namu.moe/w/늦잠(인터넷%20방송인))는 싸이코드 활동과 치지직 방송을 설명한다. 다만 수집된 `이늦잠(인터넷 방송인)` 문서 제목 자체가 기존 늦잠 채널과 동일한 인물의 문서인지 직접 확인되지 않아 후보를 자동 연결하지 않았다. 공개 시드와 DB는 변경하지 않았다.
